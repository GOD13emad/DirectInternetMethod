# Direct Internet Method 1.5.4 — Linux x86_64

Versioned Linux desktop client and protected service, targeted DNS/DPI methods, not a VPN or full-route tunnel.
Extract the archive and enter the DirectInternetMethod_1.5.4_Linux_x86_64 directory, then run ./install.sh.
Safely turn the existing Direct Method OFF through its own controls before changing an installed version.
The installer preserves byte-compatible protected files and user settings; keep a backup and official old ZIP for rollback.
Root service install may request PolicyKit authorization. Do not bypass protections or stop Tailscale/nfqws with force-kill on remote-only hosts.
Verify the latest published release and SHA256SUMS via https://github.com/GOD13emad/DirectInternetMethod/releases/latest .
HTTP 401/403, authenticated account restrictions, geographic access and all-ISP connectivity are not guaranteed.
