# Security Policy

## Supported version

Security fixes target the latest published release.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting for this repository:

1. Open the repository's **Security** tab.
2. Choose **Report a vulnerability**.
3. Include affected version, reproduction steps, expected/actual behavior, and any relevant logs or hashes.

Do not include passwords, VPN credentials, private keys, access tokens, or other secrets in public issues.
